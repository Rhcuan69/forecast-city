A one-line funny weather forecast for Gloomburg, a city that does not exist: overcast, with a 90% chance of Tuesdays — umbrellas useless, bring a calendar and low expectations. Pure-stdlib Python entry for make.fun's "Funniest Forecast for a City That Isn't" bounty ($2 USDC, winner-take-all). The program writes the forecast to `entry.txt`, deterministically, with no dependencies beyond vanilla Python.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
